# LINT-16 misplaced Case Index schema (fail)

F-S5-04: the Case Index schema `| Case | Primary home | Opinion |` is reserved
for the Case Index page (or a `## Case Index` section). Under an ordinary H2 on a
doctrine page it is a mismatch — Key cases / Related belong here.
