# LINT-9 legal anchors

A block anchor at end-of-line is masked by Quartz and is legal. ^pin-1

This paragraph ends with a block anchor after real prose. ^pin-2

A wikilink anchor reference is a LINK, not a leaked anchor: see [[Terry v. Ohio#^pin-3]].

Footnote syntax is not a block anchor.[^1]

[^1]: A footnote definition, not a leaked block anchor.
