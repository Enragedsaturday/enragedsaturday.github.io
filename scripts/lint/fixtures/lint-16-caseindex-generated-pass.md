# Case Index

schema `| Case | Holding | Good law | Home page(s) | CourtListener |`. Its
Holding + Good-law cells are projected from case-page frontmatter (S4-R10
REQUIRES a non-blank Good-law cell), so on the Case Index page (title/stem
match) the generated header is accepted, the authored-data-cell checks
(treatment token / weight label / ISO date) do not fire on the generated
columns, and a no-CL case may carry the generated "—" opinion sentinel.
