# Fixture Alpha Case

*588 U.S. 100 (2019)* · U.S. Supreme Court · **Binding — SCOTUS** · Treatment: **Good law**

## Background
The alpha parties disputed whether the fixture rule reaches the alpha scenario.

## Issue
Whether the fixture rule controls the alpha scenario.

## Rule
The fixture rule controls the alpha scenario, and the alpha exception does not apply. ^pin-100

## Application
Applying the fixture rule to these facts, the alpha exception is unavailable.

## Conclusion
Affirmed: the fixture rule controls.
